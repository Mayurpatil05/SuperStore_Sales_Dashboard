# 📊 Super Store Sales Dashboard

This project showcases an interactive Power BI dashboard built from the popular *Superstore* dataset. It highlights comprehensive sales and profit performance metrics across different dimensions such as category, subcategory, state, region, segment, ship mode, and payment type. The dashboard also includes a 15-day sales forecast using historical data trends.

## 🧾 Dashboard Overview

The dashboard includes the following key components:

- **Sales & Profit Breakdown**
  - By Category (Furniture, Office Supplies, Technology)
  - By Subcategory (Phones, Chairs, Binders, etc.)
  - By Region (West, East, Central, South)
  - By State and Segment (Consumer, Corporate, Home Office)

- **Shipping Analysis**
  - Sales by Ship Mode (Standard, Second Class, First Class, Same Day)
  - Average Ship Days

- **Time Series Analysis**
  - Monthly Sales and Profit Trends
  - 15-Day Sales Forecast (Power BI Analytics)

- **Other Insights**
  - Sales distribution by Payment Mode (Online, Cards, COD)
  - Key summary metrics (Total Sales, Orders, Profit)

## 🛠️ Tools Used

- **Microsoft Power BI Desktop**
- **Superstore Dataset (Sample Data)**
- Time Series Forecasting (Built-in analytics)
